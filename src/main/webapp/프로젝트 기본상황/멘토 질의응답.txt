1. 설문/설문지 관리
- 설문 등록 시 문항 타입과 응답 추가 방식
=> 각 문항 타입에 맞는 응답이 추가 되고 거기에 맞는 유효성이 적용되어야함.
ex) 단답형인 경우 복수응답 가능여부 같은 형태.
- 집계 조회 시 질문별 집계 및 사용자별 응답 조회 방식
=> 질문별 집계 시 해당 응답에 대한 응답 건수가 몇 건인지, 주관식인 경우는 어떤 답변들이 나왔는지 보여야함
=> 사용자 별 응답 조회인 경우는 사용자를 선택시 어떤 답변을 했는지 볼 수 있는형태
=> 추가적인 부분은 화면 구성에 따라 다름. 추후 각자 화면 설계에 맞는 코멘트를 하겠음.
2. 일반 폼
- 설문기간 아닐 경우 등록/접근 가능 여부
=> 설문기간이 아닌 경우 일반 사용자는 접근이 안되어야하고, 관리자는 접근 가능
- 설문 중복 참여 가능 여부
=> 로그인 후 참여이므로 중복참여 불가능
- 응답 후 설문 조회 가능 여부
=> 응답이 완료된 뒤엔 접근이 안되게 하고. (시간이되면 응답한 사용자인 경우 본인 응답결과는 조회가능하게)
=> 기본적으로 설문기간이 아닌경우에는 접근이 안되었으면 좋겠음.
5. 메뉴별 권한 관리
- 조회권한과 메뉴권한을 따로 관리해야하는지
=> 조회권한이 없으면 메뉴 조회가 안 되는 형태로 이해하면 좋겠음.
=> 해당 요구사항 화면에 대한 내용은 추후 멘토끼리 협의해서 결정해주겠음.
6. 권한별 사용자 관리
- 권한 목록에서 권한 유형 선택 시 해당 권한을 가진 사용자만 필터링되는지
=> 검색조건에 맞는 사용자만 조회되면 됨
- 사용자 권한 변경 방식(권한 목록에서 권한 선택, 사용자 목록에서 사용자 선택 후 적용하여 변경하는 식인지)
=> 화면 로직 정리해서 전달하겠음.
=> 권한 변경할 사용자 체크박스 선택 후 권한목록에서 권한 선택 후 적용버튼 클릭시 권한이 적용.

-설문/설문지 관리
  1. 설문지 관리에서 질문 내용 중 수정/삭제 화살표가 있는 영역이 무엇을 하는 영역인지 이해를 못하겠습니다.
  (참고를 위해 첨부파일을 추가했습니다.)
    => 기존 등록된 질문으로 보임. 화살표는 질문 순서 수정시 사용하게 되며. 수정버튼시 등록된 질문을 수정하게되고. 삭제는 등록된 질문을 삭제하는 형태
  
  2. 설문지의 질문항목을 추가할 때 구글폼에서는 콤보 박스를 열어서 [라디오/체크박스/단답형/장문형] 등을 선택할 수 있습니다.
  요구사항에서는 복수선택이란 콤보 박스만 존재하는데 어디서 질문의 유형을 선택하는지 여쭤봅니다.
  그리고 복수 선택을 하면 설문참여자가 답변을 할때 복수의 답변을 허용하는 방식인데 [단답형, 장문형, 라디오박스, 셀렉트박스] 같은 경우에는 복수 답변을 어떻게 해야하는지 모르겠습니다.
    => 구글 폼을 참고하면 되며. 복수 답변인 경우는 체크박스로 사용하면됨.
    단답형은 inputbox 형태, 장문형은 textarea, 라디오와 셀렉트 박스는 1개응답으로 생각하면 됨.
  
  3. 복수선택을 하게될 시에 항목 전부를 선택이 가능한건지 여쭤봅니다.
    => 복수응답이니 여러개 선택이 가능할 것이고
      관리자가 모두 선택가능하게할지 선택갯수 제한을 둘수있는 기능을 제공할 거면 해당기능을 만들면 됨.
      옵션을 주지 않을거면 모두 선택 가능하게 해달라.

    => 관리자 권한이 있으면 권한 관련 메뉴에 접근이 가능하고. 변경이 된다고 생각하면 좋겠음.
    단, 보통 시스템 관리자 권한 정보는 수정이 안 되게 하는데 시간이 있으면 하면 좋겠음.
